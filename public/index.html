실명 익명화 보호 모드

활성화 시, 대시보드 및 전광판에 학생 실명 대신 '번호번 학생'으로 표출하여 학생의 개인정보를 원천 보호합니다.

학생 실명 대신 번호로 표시

번호만으로 학급 일괄 생성

기존 학생 데이터를 모두 초기화하고 지정된 범위의 번호 슬롯을 초고속 자동 생성합니다.

모든 학생 점수 초기화

학급 목록(학생 이름 및 번호)은 그대로 유지하되, 모든 학생의 누적 원점수, 달성(배지) 점수, 지급 점수, 미지급 마일리지를 모두 0점으로 깨끗하게 초기화합니다.

달성 점수(Achievement) 변환 비율

학생들이 획득하는 누적 칭찬(원점수)이 몇 점 누적될 때마다 달성(배지) 1점을 환산할지 정합니다. (현재 50점 = 달성 1점)

학급 온도계 환산 규칙

전체 학생의 누적 원점수 합한 값을 몇으로 나누어 학급 온도(°)로 표시할지 정합니다. (현재 합계 ÷ 200)

kfcman.link 서비스 소개

kfcman.link는 길고 투박한 URL을 귀여운 미니어처 감성의 단축주소로 변환하여 깔끔하게 제공하는 프리미엄 유틸리티 서비스입니다.

1. 초고속 및 지능형 단축 시스템

1초 만에 최적화된 단축 URL을 배출하며, 내 도메인 및 로컬 접속 링크를 동시 제공하여 유동적인 이동이 가능합니다.

2. 정밀 유입 관제 대시보드

단축 링크의 누적 방문 클릭 횟수를 카운트하며, 방문자의 상세 IP 주소, 접속 유입 도메인 경로(Referrer)를 HSL 바 차트로 시각화하여 관제합니다.

3. 게스트 실시간 여론조사 보드

비회원 친구나 고객들이 도메인에 안전하게 접속하여 클릭 즉시 득표되는 실시간 투표를 개설할 수 있습니다. 3차원 막대그래프, SVG 도넛 차트 및 워드클라우드로 결과를 보여줍니다.

4. 다채널 승인 알림 연동

보안 위협 방지를 위한 수동 가입 승인 대기열이 작동하며, 디스코드/텔레그램 웹훅 푸시 알림, Gmail SMTP 메일 전송 및 Coolsms 카카오 알림톡으로 실시간 가입 접수를 확인합니다.
